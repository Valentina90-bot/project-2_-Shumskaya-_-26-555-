# Primitive DB

Проект примитивной базы данных в рамках домашней работы.

## Управление таблицами

Программа поддерживает следующие интерактивные команды:

* `create_table <имя_таблицы> <столбец1:тип> ...` — создать новую таблицу (поддерживаются типы: int, str, bool). Столбец ID добавляется автоматически.
* `drop_table <имя_таблицы>` — удалить существующую таблицу.
* `list_tables` — показать список всех созданных таблиц.
* `help` — открыть окно со справочной информацией.
* `exit` — завершить работу программы.

## Пример использования

```text
>>> project
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: list_tables
- users

Введите команду: exit
```

## Обновление проекта (Часть 4: Декораторы и замыкания)
В рамках финального этапа код проекта был улучшен с помощью концепций Python:
- **Обработка ошибок:** Реализован декоратор `@handle_db_errors`, автоматически перехватывающий и логирующий исключения валидации и работы с файлами.
- **Безопасность опасных операций:** Добавлен декоратор `@confirm_action(action_name)`, запрашивающий у пользователя подтверждение перед удалением данных или таблиц.
- **Замер производительности:** Реализован декоратор `@log_time` для автоматического профилирования времени выполнения дисковых операций.
- **Замыкания:** Интегрирован механизм `create_cacher()` в операцию `select` для мгновенного получения результатов повторных выборок из оперативной памяти.

Новая демонстрационная запись работы всех декораторов и подтверждения действий успешно обновлена и перезаписана в локальный файл `demo.cast`.
